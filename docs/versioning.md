# AppAudioRouter バージョニング規約 (Versioning Policy)

本ドキュメントは、`AppAudioRouter` のバージョン付与ルール、Git タグ運用、および変更管理の基準を定めます。

---

## 1. 採用方式: セマンティックバージョニング (SemVer 2.0.0)

本プロジェクトは **[Semantic Versioning 2.0.0](https://semver.org/)** に厳格に準拠します。

バージョン番号は以下の形式をとります：
```
MAJOR.MINOR.PATCH
```

| 区分 | 増番条件 | 例 |
| :--- | :--- | :--- |
| **MAJOR** (メジャー) | 後方互換性を破壊する仕様変更、対応 macOS の下限引き上げ、アーキテクチャの根本的刷新。 | `1.0.0` → `2.0.0` |
| **MINOR** (マイナー) | 後方互換性を維持した新機能の追加（例: 新しいミキシング機能、新しい CLI コマンドの追加等）。 | `1.0.0` → `1.1.0` |
| **PATCH** (パッチ) | 後方互換性を維持したバグ修正、内部リファクタリング、ドキュメント修正、パフォーマンス改善。 | `1.0.0` → `1.0.1` |

---

## 2. Git タグ運用

正式リリースおよびプレリリースには、Git タグを付与します。

### 2.1 正式リリース
- プレフィックス `v` を付けたタグ名を使用します。
  - 例: `v1.0.0`, `v1.1.0`, `v2.0.0`

### 2.2 プレリリース (Prerelease)
必要に応じてハイフン区切りのプレリリース識別子を使用します：
- アルファ版: `v1.1.0-alpha.1`
- ベータ版: `v1.1.0-beta.1`
- リリース候補版: `v1.1.0-rc.1`

---

## 3. CHANGELOG.md との関係

- 開発中の変更やコミットは、すべて `CHANGELOG.md` の **`[Unreleased]`** セクションへ記録します。
- 新バージョンをリリースする際に、`[Unreleased]` 内の項目を新しいバージョン見出し（例: `## [1.1.0] - 2026-10-15`）へ昇格させます。
- バージョン番号の引き上げ、`CHANGELOG.md` の更新、および `scripts/package_app.sh` 内の `CFBundleShortVersionString` は同一のリリースコミットで同期して変更します。
